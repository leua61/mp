最终分类规则：
- M 杂项：只收非四字固定表达或确有保留价值的非常见短词，位置在最左。
- L 清涧｜一级：常见，而且现代汉语一眼即可理解；高中及以前系统接触过的熟词原则上不抬高。
- O 林翳｜二级：常见，或语文较好者可现场拆字、拆古义、辨固定搭配后理解；有门槛，但字面不会强烈诱导错误答案。
- E 蜃景｜三级：字面看似好懂，却容易推出错误含义，重点防望文生义、今古义错位和固定对象误判。
- F 玄渊｜四级：非基础教育熟词，且依赖生僻典故、冷僻专名／器物义，或含关键难读生僻字。

本版关键变化：
- “随行就市”由 L 调整为 O。
- 第二级不再只剩少量冷词，而是系统接纳常见但有拆解门槛的词。
- 万人空巷、差强人意、不刊之论、望其项背等集中进入 E，避免与“只是稍难”混为一谈。
- 高山仰止按“容易从字面误解”调整为 E；马放南山、不分畛域、东床快婿继续保留 F。
- 蚍蜉撼树、醍醐灌顶、越俎代庖、饮鸩止渴等因关键生僻字／典故门槛进入 F。
- 本轮重分 552 条：L→O 412，L→E 80，L→F 22，E→O 19，E→F 13，F→E 6。
- 当前共 1611 条：M61 / L914 / O441 / E106 / F89。
- M → L → O → E → F；详情区仍为左栏放不下后自动续到右栏。
